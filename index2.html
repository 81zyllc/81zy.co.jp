// Background

2001年からエンジニアとしてキャリアをスタート。25年以上にわたり、大手通信・金融・放送・EC・不動産など多様な業界でシステム開発を担当。プロジェクトリーダー・PM・マネジャーとして大規模チームの統括経験を持ちます。

// Recent Focus

直近ではSaaS のインフラ構築・運用支援（Azure / Terraform / Container Apps / Azure OpenAI）や、大規模 Aurora MySQL バージョンアップ対応など、クラウドネイティブな案件を中心に担当。

// Style

スタートアップから大規模システムまで、フェーズを問わず柔軟に対応。技術的な意思決定を共に担い、チームと長期的な信頼関係を築くことを大切にしています。
